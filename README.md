# Trello Clone - MERN Stack

Clone de Trello réalisé avec la stack MERN.

## Fonctionnalités (Phase 1)
- Authentification (JWT)
- Boards (CRUD)
- Lists avec ordre
- Cards avec ordre
- Sécurité par utilisateur

## Stack
- MongoDB
- Express.js
- React.js
- Node.js

## Installation
```bash
git clone git remote add origin https://github.com/Roberto05-cpu/cloneTrello.git
cd cloneTrello
npm install
